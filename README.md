# 🚀 API de Cadastro de Usuários — Spring Boot & PostgreSQL

Projeto backend desenvolvido em **Java com Spring Boot**, como parte da minha jornada no curso **Javanauta**, com foco em boas práticas, organização de código e integração com banco de dados relacional.

A aplicação consiste em uma **API REST** responsável pelo cadastro e gerenciamento de **usuários**, incluindo **endereços** e **telefones**, seguindo um modelo comum em sistemas reais.

---

## 📌 Funcionalidades

- 👤 Cadastro de usuários (nome, e-mail e senha)
- 📍 Cadastro de endereços vinculados ao usuário
- 📞 Cadastro de telefones vinculados ao usuário
- 🔗 Relacionamento entre entidades (User, Address, Phone)
- 📦 API REST com troca de dados em JSON
- 🗄️ Persistência de dados com PostgreSQL

## 🧱 Arquitetura do Projeto

O projeto segue uma estrutura baseada em boas práticas do Spring Boot:

- **Controller** → Camada responsável pelas requisições HTTP
- **Service** → Regras de negócio
- **Repository** → Acesso ao banco de dados (JPA)
- **Entity** → Mapeamento das tabelas do banco
- **DTO (quando aplicável)** → Transporte de dados
